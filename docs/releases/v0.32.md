<!-- Release notes for v0.32. The release workflow publishes this file as the GitHub release text. -->

Pheeme can now put the events from an emailed `.ics` file on your Google Calendar, and copying a sign-in code from the mail list marks that email read.

**Calendar**
- Click an `.ics` file in an email, like a season schedule from a coach or a booking confirmation, to open **Add to Google Calendar**. It lists every event in the file, and when there are several, the ones you can add start ticked: untick any you don't want, pick a calendar, and add them.
- Events are added as plain copies with no organizer or guests, so nobody is emailed. A repeating event keeps its moved and cancelled sessions.
- If the file is an invitation you're a guest of, the button is **Add and accept**: it puts the event on your calendar and tells the organizer you're going.
- Events already on one of your calendars say which one. When every event is already there, the button is **Open in Calendar**.
- For a file that isn't an invitation to you and isn't on your calendar yet, the invite card now offers **Add to calendar** instead of asking whether you're going. Answering used to add you as a guest and email the organizer.

**Mail**
- Copying a sign-in code from the chip on a mail-list row now also marks that email read, on every device, so it isn't left waiting in your inbox once you've used the code. It's only marked read when the copy worked.
