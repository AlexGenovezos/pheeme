<!-- Release notes for v0.35. The release workflow publishes this file as the GitHub release text. -->

Do more of what Gmail does without leaving Pheeme: filters, a vacation responder, Report spam, richer formatting, Show original and forwarding as attachments.

**Mail**
- **Filters:** "Filter messages like these" in a conversation's More menu opens Gmail's filter form with the sender already in From. It can skip the Inbox, mark as read, star, label, forward, delete, set importance or categorize, and it can also apply to the conversations that already match. Settings › Filters lists every filter on each account, with Edit and Delete (Delete has Undo).
- **Report spam** (`!`) is in the More menu, the row menu and the palette, with Undo.
- **Importance:** mark conversations important or not important with `+` and `-`, from the menus, or by clicking the new marker at the start of each row.
- **Unsubscribe** now shows beside the sender of mailing-list messages. After you confirm, Pheeme unsubscribes in one click, or opens the sender's page, or gets an email ready to send, depending on what the sender supports.
- **Show original** displays a message's source: its Message ID, the SPF/DKIM/DMARC results, **Download original** (`.eml`) and **Copy to clipboard**. It's in the More menu and in the new ⋮ menu on each message.

**Compose**
- The formatting bar now has Gmail's options: font, size, text and background colour, alignment, indent, quote, strikethrough and remove formatting. Gmail's shortcuts work too, such as `mod+shift+x` and `mod+\`. Other mail apps show the formatting the same way Gmail does.
- **Insert emoji** opens a searchable picker that keeps recently used emoji and stays open while you pick several.
- **Forward as attachment** attaches each message as an `.eml` file. It works on a whole conversation, several checked conversations, or a single message from its ⋮ menu.

**Vacation responder**
- Settings › Vacation responder sets Gmail's own out-of-office reply for each account, so every device shows the same one. While it's on, a corner card says so and offers **End now**.
- It needs permission to manage your basic mail settings. If an account was signed in before Pheeme asked for it, Settings asks you to **Sign in again** first.

**Calendar**
- When an event starts, its "Now" reminder replaces the "In 10 minutes" notification instead of appearing beside it, on macOS, Windows and Linux.

**Fixes and speed**
- Pheeme no longer crashes when it quits or restarts after an update while the database is busy.
- "Pheeme is up to date" now goes away after 5 seconds.
- Opening conversations no longer crashes the reading pane. If a part of the window does fail, only that part shows an error with a way to recover, not a blank window.
- Dialogs keep keyboard focus properly.
- Pheeme uses less memory and does less repeated work while you read mail and browse the calendar.
- Sign-in refreshes and calendar changes no longer race with background sync.
- Security hardening covers the assistant (MCP) server, mod installs and PowerPoint previews.
