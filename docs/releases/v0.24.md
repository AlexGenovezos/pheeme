<!-- Release notes for v0.24. The release workflow publishes this file as the GitHub release text. -->

Forward or reply to any email in a conversation, a much lighter sidebar for very large mailboxes, Add account in a dialog, and a security fix to how emails are displayed.

**Mail**
- Each email in a conversation of several now has its own **Reply**, **Reply all** and **Forward** buttons beside its date, so you can answer or forward an earlier email. When a message bounces, Gmail puts the bounce in the same conversation, so before this **Forward** (`f`) sent the bounce and the original couldn't be forwarded.
- The toolbar's buttons and `r`, `a` and `f` still answer the latest email.

**Speed**
- The sidebar's label counts are only counted again when your mail changes. Before, every sync of any account recounted them all, which in a mailbox of hundreds of thousands of emails took several seconds each time and slowed everything else down.

**Accounts and Settings**
- **Add account**, **Sign in again** and Settings › About › **Open guide** open in a dialog over your mail, the size of Settings, instead of taking over the window. Cancel, `Esc` or clicking outside closes it. With no account connected yet, setup still fills the window.
- In Settings › MCP, **Connect** shows the command in a dialog instead of growing the page, and `Esc` closes only that dialog.

**Security**
- Updated the library that cleans email HTML before showing it, to fix a published flaw (RUSTSEC-2026-0533) that a crafted email could use to slip script-like content past it.

**Heads-up**
- This version updates the local mail cache (`014_thread_versions.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
