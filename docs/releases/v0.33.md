Print an email conversation, and paste images straight into the message you're writing.

**Mail**
- Print the open conversation with `⌘P` on macOS or `Ctrl+P` on Windows and Linux, from its More menu, or from the command palette. A clean page opens with the subject, each message's sender, recipients, date and text, and the names of its attached files, followed by the system's print dialog.
- Messages whose full text hasn't downloaded are fetched before printing. If any still show only a preview, Pheeme tells you.

**Compose**
- Paste an image into the message body and it appears at the cursor, between your words. Recipients see it there too, and reopening a saved draft keeps it in place.
- Delete an image from the text to leave it out of the email; undo brings it back. Pheeme waits for pasted images to finish processing before saving the draft.
- Embedded images in quoted replies now travel with the message body so mail clients can display them in place.

**Security**
- Updated dependencies to fix two RustSec advisories involving cookie encryption and URL parsing.
