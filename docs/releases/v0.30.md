<!-- Release notes for v0.30. The release workflow publishes this file as the GitHub release text. -->

Pheeme keeps huge mailboxes quick, shows the mailbox download as it happens, and lets you recolour your calendars.

**Mail**
- Sidebar and tray counts are now instant on very large mailboxes. On a mailbox of hundreds of thousands of messages, the inbox no longer waits minutes behind them. The first launch after updating spends a few seconds (up to about 20 on the largest mailboxes) preparing the counts.
- Email images that fail to load are tried again after a moment and show once they arrive.
- The account rail setting is gone. The sidebar always shows All Inboxes and each account, and `Ctrl+Tab` still steps through them.

**Sync**
- While a mailbox downloads (the first launch, or a new account), the bottom-right corner shows how far along it is, and that you can keep using Pheeme meanwhile. ✕ hides it.
- Being offline, Gmail slowing sync, a failed sync and **Sign in again** now show in that same corner, instead of pushing the sidebar down or getting cut off.

**Calendar**
- Recolour a calendar from its palette button in the sidebar (or right-click the row) with Google Calendar's 24 colours. The colour is saved to your Google calendar list, so the web and your phone show it too. Pheeme asks for one more Google permission the first time.

**Fixes**
- Opening Pheeme while it's already running brings up its window, instead of stopping with "Pheeme is already using this data folder".
- Toasts stay in the bottom-right corner above any open draft, instead of covering the sidebar footer.
- Settings and Stats grow with the window, like T3 Code's dialogs.
- Diagnostics reports say why an email's images didn't load, and include each account's mail counts.
- Message building uses lettre 0.11.24, which fixes six security advisories.

**Heads-up**
- This version updates the local mail cache (`020_thread_counts.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
