<!-- Release notes for v0.18. The release workflow publishes this file as the GitHub release text. -->

AI assistants can work with your mail through Pheeme, plus your own signatures and themes, PowerPoint previews, and calm behaviour when you go offline.

**AI assistants (MCP)**
- **Settings › MCP** lets an AI assistant such as Claude Code search and read your mail through Pheeme. It's off by default. **Connect a client** shows a token once, with the command to paste into your assistant. Setup is in the [MCP guide](https://github.com/AlexGenovezos/pheeme/blob/main/docs/mcp.md).
- Assistants can also archive, star, mark read, label and trash mail, create and delete Gmail filters, and write drafts for you to send. Each group has its own switch, all off by default. Assistants can never send mail.
- Ask "what are my filters deleting that they shouldn't?" or "who should I unsubscribe from?": assistants can list your busiest senders, show recent mail matching each filter that deletes or archives, and unsubscribe for you (its own switch) from lists that offer one-click unsubscribe. For other lists they give you the link or address.
- **Activity** in Settings › MCP lists the recent calls an assistant made: what it sent, and what came back (a change's full answer, or the conversations and senders a read returned).

**Compose**
- Your Gmail signature now appears in new messages and replies. **Settings › Signatures** shows it for each account, lets you write your own instead, and picks Gmail's, yours or none separately for new messages and for replies and forwards.
- The signature sits above the quoted text as one block, so logos and tables stay intact. Changing From on a new message swaps in that account's signature. Drafts written by assistants don't include your signature yet.

**Themes**
- Make your own theme in Settings › Appearance with **Create…**, or customize one with the button next to it: a live editor that builds a palette from a background and an accent, or lets you set every colour.
- T3 Code theme files import directly, and any theme can go in either the Light or Dark slot.
- Theme files dropped into the themes folder show up in Appearance by themselves.

**Reading mail**
- PowerPoint (`.pptx`) attachments preview slide by slide, like PDFs.
- When Pheeme can't reach Google, it stops retrying and shows one "Offline. Changes will sync later." note instead of a sync error on every account. Archiving, starring, changing labels on mail and sending wait in the queue meanwhile, and everything syncs as soon as the connection is back.

**Fixes**
- Screen readers read verification codes aloud, conversation rows and sidebar items read as their visible text, and `Tab` can get back to the file in an attachment preview.
- Settings › Accounts no longer jumps while sync progress and network addresses load.
- On macOS, System mode no longer flickers when a light theme is used while the Mac is in dark mode.

**Under the hood**
- The groundwork for the calendar is in place: Pheeme can download and sync your Google calendars and change events. You'll see it in a coming release.

**Heads-up**
- This version updates the local mail cache (`010_calendar.sql`, `011_assistant.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
