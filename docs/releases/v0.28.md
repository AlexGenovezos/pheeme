<!-- Release notes for v0.28. The release workflow publishes this file as the GitHub release text. -->

Pheeme shows which account you're in, the calendar draws when it'll rain, and you can attach screenshots when you send diagnostics.

**Mail**
- Settings › Appearance › **Current account** adds three ways to see which account you're in. **Glow** (on by default) lights the open account's group in the sidebar in its color. **Account color across the window** adds a stripe along the top of the window and a tint behind the list's title. **Account rail** puts All Inboxes and each account as icons beside the sidebar, with unread counts. Picking one opens the same Inbox tab or favorite (Starred, Sent, …) in that account when it has one, else its first Inbox tab. With a single account none of them show, and glow and window color stay off in All Inboxes.
- Account initials skip punctuation ("Avery (Studio)" is "AS"), in the rail and in sender avatars.

**Calendar**
- With weather on, Day and Week draw the hourly forecast in the hours themselves: rain in the hours it's due, a warm wash on sunny mornings, and snow, storms and fog where they fall. Cloudy hours stay plain. The bands move for a few seconds when new days appear or you point at a day, then hold still, so a calendar at rest uses no battery on animation.
- **Create event from email** gives a clean description: the email's new text, without the quoted thread, signature or a newsletter's hidden preview text, and a link back to the email in Gmail. A reply's time no longer comes from its quoted "On … wrote:" line.
- **Open in Google Calendar** works again, in the event popover and on the invite card. Links in an event's description can be clicked.
- Answering an invite with the keyboard keeps your place on the Yes / Maybe / No buttons while the answer is sent.
- The time zone note's dismiss button stays inside the card when the sidebar is narrow.

**Diagnostics and privacy**
- Settings › About › **Send diagnostics** takes up to 3 screenshots: paste, drop or pick them. Each is redrawn as a plain image before it's sent, so nothing hidden in the file (location, extra data) goes with it.
- **Share anonymous usage stats** now also counts, per day, which screens are opened and for how long, which commands are used by shortcut, palette or button, which shortcuts you've changed, and how many accounts are connected. Never label names, searches or anything from your mail. Turning the switch off deletes counts not yet sent.

**Heads-up**
- This version updates the local mail cache (`017_usage_counts.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
