<!-- Release notes for v0.8. The release workflow publishes this file as the GitHub release text. -->

You can write mail now: new messages, replies and forwards, with drafts and undo send.

**Compose**
- New message with `c` or the pen button at the top of the sidebar. With more than one account, pick which one it's from.
- Reply (`r`), Reply all (`a`) and Forward (`f`) always send from the account that got the message. The quoted original is folded away behind `…`.
- Recipients become chips as you type or paste. A typo'd address turns red and holds the send until it's fixed.
- Bold, italic, underline, lists and links. Attach files from the paperclip or by dropping them on the message, with a running total against Gmail's 25 MB limit.
- Panels sit at the bottom right, up to three at once. Minimize one to keep it for later.

**Drafts**
- Drafts save to Gmail every 30 seconds while you write, so they're on your phone too.
- Closing a message with unsaved changes asks whether to save it as a draft or discard it.
- A draft inside a conversation shows **Edit draft** to pick it back up.

**Sending**
- `Cmd/Ctrl+Enter` sends. For 5 seconds you can **Undo**, and the message comes back exactly as it was.
- Change the wait (Off to 30 seconds) in **Settings › Compose**.
- If Gmail refuses a message, it reopens with the reason, so nothing you wrote is lost.

**Settings**
- One Settings window (`Cmd/Ctrl+,` or the gear in the sidebar) for theme, accounts, compose and keyboard shortcuts.
- Every shortcut can be changed: click it and press the new keys. Two-key sequences like `g i` work too.

**Reading**
- HTML emails look like they should again: their own fonts, colors and highlights load, and dark mode applies to them. In v0.7 they showed as plain black text.
