<!-- Release notes for v0.31. The release workflow publishes this file as the GitHub release text. -->

Pheeme keeps Spam's tracking images hidden, keeps the mail list quick after every sync, and stops showing two Pheemes in the Dock after an update.

**Mail**
- Emails in Spam no longer load remote images on their own, just like Gmail. This stops tracking pixels from telling the sender that your address is real, when you opened the email, or where you were. Choose **Show images** above the email to see them for that message.
- On large mailboxes with several accounts, the sidebar no longer holds up the mail list after each sync.
- A sync that finds nothing new now finishes in a fraction of the time it used to take.

**Fixes**
- On macOS, Pheeme comes back in its pinned spot in the Dock after an update restarts it, instead of showing a second copy beside it. This works from the update after this one, because the version being replaced is the one that does the restart.
