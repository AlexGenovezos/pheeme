<!-- Release notes for v0.34. The release workflow publishes this file as the GitHub release text. -->

Print just one email, follow notifications straight to their message, and preview PDFs on older Macs.

**Mail**
- Each expanded message has a printer button that prints just that email. In Settings › Reading › Printing, choose whether `⌘P` on macOS or `Ctrl+P` on Windows and Linux, the More menu and the command palette print the whole conversation or **Latest message**, the message Reply would answer.
- PDF attachments now preview on Macs with Safari older than 26.2. If a page still can't be drawn, its preview shows an error instead of staying blank.

**Notifications**
- Clicking a new-mail notification expands and scrolls to the message it showed, even when its conversation is already open.
- A conversation's notification goes away when you read, archive, trash or delete it. Changes made on another device take effect after the next sync. New replies replace that conversation's earlier notification instead of stacking up.

**Diagnostics**
- Calendar and Tasks logs now show how long changes take and where the time goes, helping diagnose slow operations. Diagnostics reports also include macOS, Safari and WebKit versions on a Mac.
