<!-- Release notes for v0.12. The release workflow publishes this file as the GitHub release text. -->

Large mailboxes feel quicker: **Unread only** switches instantly, and sync no longer stalls while older mail downloads.

**Speed**
- **Unread only** shows the unread mail already on screen the moment you turn it on, and fills in the rest right after. Turning it off brings the full list straight back.
- Tabs with only a few unread conversations, like Updates or Forums, load their unread list in about a hundredth of a second on a 200,000-conversation mailbox. They used to take a fifth of a second every time.
- Downloading older mail in the background gives way to everything else, so syncing, sending and opening mail stay quick while it runs.

**Sync**
- Raised your Gmail API limit in Google Cloud Console? Enter it in **Settings › Sync › Gmail API limit** and Pheeme syncs faster to match.

**Storage**
- Attachments and images you've opened are kept to about 500 MB on disk. Removing an account deletes its cached attachments too.

**Heads-up**
- This version updates the local mail cache (`006_app_settings.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
