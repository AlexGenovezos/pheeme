<!-- Release notes for v0.13. The release workflow publishes this file as the GitHub release text. -->

Manage your Gmail labels in Pheeme, move through mail without waiting, and see how much of your mailbox has synced.

**Labels**
- Create, rename, nest, colour, hide and delete labels from the sidebar. Changes sync with Gmail.
- Press `l` for a searchable **Label as…** picker, or `v` to **Move to…** a label. You can create a label straight from the picker.
- Coloured label chips appear beside your mail. All Mail, search and other mixed views also show where a conversation lives: an inbox category, Sent, Drafts, Spam, Trash or Archived.

**Reading and search**
- Pheeme preloads upcoming conversations and images as you move through the list, and warms inbox tabs in the background. Switching emails no longer flashes the message body.
- **Settings › Appearance › Preload images** turns image preloading off while keeping text preloading. It is on by default; loading remote images can tell senders you opened an email, along with your IP and rough location, even if you skip it. Preloading never marks mail as read.
- Press `Right` to focus the open email, then use the arrow keys, Page Up/Down or Space to scroll. Press `Left` to return to the conversation list.
- Search keeps the previous results visible while you type, until the new results arrive.
- Opening an email takes priority over the background mailbox download. If it takes longer, the reading pane explains what it is waiting for and offers a retry when it fails.

**Sync and diagnostics**
- **Settings › Accounts** shows a live progress bar and synced/total message counts for each mailbox, with downloaded message bodies counted separately.
- **Settings › About** lets you send diagnostics or save a copy to share when troubleshooting. If uploading fails, saving a copy is still available.

**Desktop and setup**
- Pheeme asks whether to turn on notifications for each account. Dismissing the prompt leaves them off; you can change your answer in Settings.
- Hide the menu bar or notification-area icon in **Settings › Notifications**. With the icon hidden, closing the window quits Pheeme. The tray menu now contains Open and Quit.
- The Windows installer shows progress and opens Pheeme when finished, without a setup wizard.
- First launch explains why setting up your own Google Cloud app keeps Pheeme free, before starting the setup guide. You can also receive a setup from another device.

**Heads-up**
- This version updates the local mail cache (`007_sync_progress.sql`). Once it has run, older versions can't open the cache, so keep auto-update on.
